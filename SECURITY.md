# Security Policy

## Supported Versions

Only the latest major version of MIYO-STREAM is currently supported with security updates.

| Version | Supported          |
| ------- | ------------------ |
| 2.x.x   | :white_check_mark: |
| < 2.0   | :x:                |

## Reporting a Vulnerability

Please do **not** report security vulnerabilities through public GitHub issues.

If you believe you have found a security vulnerability in the MIYO-STREAM source code, its proxy APIs, or caching layers, please report it privately via email to:

📧 **[contact@cyber-winner.site](mailto:contact@cyber-winner.site)**

We take all security reports seriously. We will acknowledge receipt of your vulnerability report within 48 hours and strive to send you regular updates about our progress in verifying and patching the vulnerability.

Once the vulnerability is patched, you will be credited in our public security advisory (if you wish to be credited).
